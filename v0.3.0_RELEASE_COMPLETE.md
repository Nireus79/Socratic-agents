## Answer Processing Workflow

The orchestrator now implements the complete 7-step workflow:

1. Extract specs from user response
2. Filter by confidence >= 0.7 (monolithic pattern)
3. Merge high-confidence specs into project fields
4. Detect conflicts using filtered specs
5. Update project maturity
6. Auto-generate follow-up question
7. Store follow-up in conversation_history
