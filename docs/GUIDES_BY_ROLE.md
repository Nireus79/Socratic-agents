# Socratic Agents - Guides by Role

## For Developers

Extend by:
- Creating custom agents (inherit from BaseAgent)
- Implementing agent-specific logic
- Integrating with frameworks

## For ML/Data Scientists

Use for:
- Multi-step workflows
- Agent-based learning
- Adaptive optimization

Typical workflow:
1. Select agents for task
2. Configure with LLM client
3. Orchestrate execution
4. Analyze results

## For DevOps

Deploy:
- As Openclaw skills
- In LangChain agents
- As microservices

## For Business Users

Benefits:
- Specialized agents for different tasks
- Automatic skill optimization
- Better workflow automation
